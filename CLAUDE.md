# Правила для всех, кто работает с репозиторием (Claude, GPT Astra, люди)

1. Перед началом: `git pull`.
2. Каждая задача — в отдельной ветке, затем Pull Request в `main`. Один PR — одна задача.
3. Не коммитить данные склада, резервные копии, выгрузки Excel, пароли и токены.
4. Приложение остаётся одним самодостаточным файлом `index.html`, без внешних скриптов: склад должен работать без интернета.
5. Проверка перед PR: телефон (390 px) и компьютер, без ошибок в консоли; старые резервные копии должны по-прежнему загружаться.
6. Оформление аккуратное и единое по всему приложению.
