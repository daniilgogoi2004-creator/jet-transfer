# Склад · Джет Трансфер

Система учёта запчастей для техорганизации «Джет Трансфер»: приход и выдача, QR-коды пакетов, ячейки, импорт и экспорт Excel, резервная копия.

## Как открыть

Один самодостаточный файл `index.html`: библиотеки Excel (SheetJS) и QR встроены внутрь, интернет для работы не нужен (кроме шрифтов).

Локально:
```
python -m http.server 8000
```
и открыть http://localhost:8000

## Данные

Данные склада хранятся в браузере устройства (localStorage) и в файлах резервных копий. В репозиторий данные не попадают и попадать не должны.
